Projeto de emulador de Mega Drive para Sega Saturn, conforme o contexto fornecido pelo responsável.

## Estado da migração

O marco a preservar é **v0.6**, indicado pelo responsável como estado confirmado. Os fontes, binários, resultados de testes e detalhes técnicos dessa versão ainda não foram disponibilizados nesta migração.
